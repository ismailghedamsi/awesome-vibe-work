# Categories

Scope notes for each category in this list.

- **Office & productivity** — complete work apps: word processors, spreadsheets, presentation editors, note-taking and task apps. A single-purpose converter or viewer belongs in Web apps & SaaS instead.
- **Creative tools** — image, vector, video, photo-library, PDF, motion-graphics, page-layout, and 3D apps. The vibe-built creative suite shelf.
- **Games** — playable games. Game *engines* and tooling go under Developer tools.
- **Developer tools** — editors, terminals, CLIs, API tools, and agent infrastructure that was itself vibe-built.
- **Web apps & SaaS** — hosted products and browser utilities with real users that don't fit the office or creative buckets.
- **Mobile apps** — native iOS/Android apps shipped to stores. Web apps wrapped for mobile stay in Web apps.
- **Music & audio** — instruments, DAWs, effects, and generative-audio toys.
- **Data & visualization** — dashboards, explorers, and visualizers where the data engine or the visualization layer is the impressive part.
